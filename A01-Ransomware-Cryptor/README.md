
# A01 Ransomware / Cryptor Class

|ID|Technique|Dominant APIs / Mechanisms|Static Artifacts (Ghidra)|Dynamic Artifacts (Procmon / PCAP / Sysmon)|Semantic Meaning|
|---|---|---|---|---|---|
|**A01_1**|Local File Encryption|`FindFirstFile`, `FindNextFile`, `CreateFile`, `ReadFile`, `WriteFile`, crypto APIs (AES via Crypto++ / .NET / custom)|Directory traversal logic, file I/O imports, crypto routines (AES loops or library calls), file extension filters|High-volume file reads/writes, rapid file modification, no UI, no network, no process spawn|Enumerates and transforms local files into an unusable encrypted state without additional coercion or signaling|
|**A01_2**|File Encryption + Ransom Note |Same as A01_1 + `CreateFile` (note), `MessageBox`, `SystemParametersInfo` (wallpaper), optional registry writes|Ransom note strings, payment instructions, email/Bitcoin strings, UI-related imports, dropped note filenames (e.g., `READ_ME.txt`)|File encryption activity + creation of ransom note files, possible UI popups, wallpaper changes, minimal or optional network traffic|Encrypts files and communicates coercive instructions to the user to induce payment or compliance|
|**A01_3**|Recovery Inhibition / Destructive Prep|A01_1 APIs + `system`/`CreateProcess` (e.g., `vssadmin`), `DeleteFile`, registry modification APIs (`RegSetValueEx`), service control APIs|Strings referencing `vssadmin`, `shadow`, `backup`, registry paths, command-line artifacts, system utility invocation patterns|Execution of system utilities (shadow copy deletion), deletion of backup-like files, registry/service modifications, followed by encryption activity|Disrupts or removes recovery mechanisms to prevent restoration of encrypted data, increasing irreversibility|
|**A01_4**|Encryption + Exfiltration / Double-Extortion Signaling|A01_1 APIs + `WinHttpOpen`, `WinHttpConnect`, `WinHttpSendRequest`, `InternetOpen`, or sockets APIs (`send`, `connect`)|Hardcoded domains/IPs, HTTP paths, user-agent strings, serialization/encoding routines, file metadata collection logic|File encryption + outbound network traffic (HTTP/DNS), possible upload of file metadata or contents, beacon-like communication|Combines file encryption with data exfiltration or signaling to increase leverage via threat of data exposure|
