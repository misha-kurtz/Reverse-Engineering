A05_3 Protocl Mimicry

Summary

Performs periodic outbound HTTP POST requests designed to 
mimic legitimate REST-style telemetry traffic generated by 
a desktop application. The sample uses the .NET HttpClient 
API to transmit structured JSON telemetry data to a controlled 
API endpoint while incorporating browser-style HTTP headers, 
application metadata, version identifiers, and realistic client 
request patterns.

The specimen intentionally disguises simple beaconing behavior 
as benign application telemetry by emulating common characteristics 
observed in legitimate SaaS clients, update agents, analytics software, 
and endpoint telemetry frameworks. This demonstrates controlled protocol 
mimicry behavior commonly associated with malware attempting to 
blend malicious command-and-control traffic into normal enterprise 
network activity.

Payload Summary
No secondary payload is delivered or executed by this sample.

To execute A05_3_protocol_mimicry:
.\A05-Beaconing-C2-Networking\A05_3\bin\A05_3_protocol_mimicry.exe

#########################################################################

High-Level Beacon Flow:

1. Configure target telemetry endpoint: http://api.lab.local/v1/telemetry
2. Initialize .NET HttpClient
3. Configure browser/application-style HTTP headers:
    User-Agent
    Accept
    Accept-Language
    X-Client-Version
    X-Request-Origin
4. Build structured JSON telemetry payload containing:
5. Session identifier
    Event type
    UTC timestamp
    Application name
    Version metadata
    Operational status
6. Submit HTTP POST request with JSON body
7. Receive HTTP response from server
8. Sleep for fixed interval
9. Repeat for configured iteration count

INetSim HTTP Server Config for A05_3

Create a fake telemetry response file:
sudo nano /var/lib/inetsim/http/fakefiles/a05_3_telemetry.json 
{"status":"ok","message":"A05_3_TELEMETRY_ACK"}

Set ownership:

sudo chown inetsim:inetsim /var/lib/inetsim/http/fakefiles/a05_3_telemetry.json

Add the following mapping to /etc/inetsim/inetsim.conf:
http_static_fakefile /v1/telemetry a05_3_telemetry.json application/json

Restart inetsim
sudo systemctl restart inetsim
